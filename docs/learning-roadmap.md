# 4 周学习路线

## 第 1 周：搭建学习节奏与 Git 基础

目标：先把本地学习仓库用起来，养成记录习惯，并掌握最常用的 Git 操作。

- 完成仓库目录整理
- 学会 `git init`、`git status`、`git add`、`git commit`
- 每天至少写一段学习记录
- 熟悉 Markdown 的基础写法

建议产出：

- 1 份 Git 入门笔记
- 2 个简单代码片段
- 3 篇学习日志

## 第 2 周：Python 基础语法与小练习

目标：用 Python 巩固变量、列表、循环、函数和文件读写等基础内容。

- 练习字符串和列表的常见操作
- 写 2 到 3 个可运行的小脚本
- 记录每个脚本解决了什么问题
- 整理常见报错和排查方式

建议产出：

- 1 份 Python 入门笔记
- 2 个以上 Python 示例
- 1 次针对报错的复盘记录

## 第 3 周：C++ 基础与数据结构入门

目标：理解 C++ 的基本语法、编译运行方式，以及 `vector` 等常用容器。

- 熟悉变量、条件、循环、函数
- 学会使用 `vector` 存储和遍历数据
- 尝试用编译器执行一个完整示例
- 对比 Python 与 C++ 在语法上的不同

建议产出：

- 1 份 C++ 基础笔记
- 1 个 `vector` 练习程序
- 1 段关于编译命令的说明

## 第 4 周：前端基础与综合复盘

目标：补齐 HTML、CSS、JavaScript 的入门理解，并回顾前 3 周的学习内容。

- 理解页面结构、样式和交互的分工
- 用 JavaScript 练习数组与函数
- 汇总前 4 周遇到的高频问题
- 调整下一阶段学习重点

建议产出：

- 1 份前端基础笔记
- 1 个 JavaScript 小练习
- 1 份阶段复盘

## 执行建议

- 每次学习控制在一个清晰主题内
- 笔记尽量配短示例，不只写概念
- 不追求一天学很多，优先保证连续性
- 每周末回看日志，调整下周安排
