# daily-learning-lab

一个用于记录个人软件开发学习过程的本地仓库，重点放在持续积累，而不是追求一次性做很多内容。

## 仓库定位

这个仓库用于整理我在日常学习中的输入与输出，主要包含：

- 学习笔记：记录基础概念、常用命令和入门示例
- 代码片段：保存可以独立运行的小练习
- 问题复盘：整理学习中遇到的具体问题和排查思路
- 阶段计划：把短期学习目标拆成可执行的小步骤

## 当前技术方向

- Python
- C++
- 前端基础
- Git
- 软件工程基础

## 使用方式

1. 先阅读 `docs/learning-roadmap.md`，了解最近 4 周的学习安排。
2. 在对应笔记中补充概念理解、命令示例和踩坑记录。
3. 运行 `snippets/` 下的小程序，边看边改，巩固基础语法。
4. 每次学习后写一篇简短日志，记录问题、思路和下一步计划。

## 维护原则

- 内容尽量具体，不写空泛总结
- 示例尽量小而完整，确保可以单独运行
- 日志真实记录学习过程，不夸大进度
- 优先打牢基础，再逐步增加复杂度
