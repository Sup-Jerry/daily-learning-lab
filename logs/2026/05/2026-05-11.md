# 学习日志 - 2026-05-11

## 今日学习

今天继续把学习节奏放慢一点，重点不是追求新内容，而是把已经接触过的基础知识再过一遍。我主要回看了 Git、Python 和前端基础这几个方向，尤其在意“自己是不是真的记住了”。相比只看笔记，重新打开之前写过的小示例会更直接，因为一旦看到代码，就能立刻发现哪些地方只是眼熟，哪些地方才算真正理解。

## 遇到的问题

今天的问题不算难，但很真实：学过的内容如果隔一天不碰，就会变得模糊。比如 Git 命令大概知道用途，但一到自己操作时，还是容易混淆 `add`、`commit` 和 `push` 的顺序；Python 和 JavaScript 里一些相似的语法，看笔记时觉得简单，真正回忆时却不够稳定。说明现在更缺的是重复和整理，而不是继续不断加新知识点。

## 解决思路

我准备继续用“小笔记 + 小示例 + 小日志”的方式巩固内容。笔记负责整理概念，示例负责验证理解，日志负责记录当天到底卡在什么地方。这样做虽然看起来很朴素，但更适合当前阶段。比起一次学很多，不如把每天接触到的内容都压缩成自己能复述、能修改、能再写出来的东西。

## 明日计划

明天准备挑一个最基础的主题做一次小复盘，比如专门整理 Git 的常用流程，或者重新写一个更简单的 Python 练习。目标不是增加数量，而是让已有内容更扎实一点。

## 补充记录

今天也继续保持了仓库记录的习惯。哪怕只是新增一篇日志，也是在给后面的自己留下学习轨迹。长期来看，这种持续的小更新会比偶尔一次性写很多内容更有价值。
