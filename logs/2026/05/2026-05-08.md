今天先把学习仓库的基本结构搭起来，顺手整理了一下接下来一段时间准备持续记录的内容。我先看了 Git 最常见的几个命令，把 `git init`、`git status`、`git add` 和 `git commit` 的作用重新过了一遍。以前知道这些命令能用，但经常是照着教程敲，隔几天又忘。今天边记边写，感觉比只看视频更容易留下印象。除了 Git，我还简单回顾了 Python 列表和循环的写法，准备后面把一些小练习也放进仓库里。

## 遇到的问题

最大的问题不是命令本身，而是学习内容容易散。之前我经常把笔记写在不同地方，过几天就找不到，也不知道自己到底学到了哪一步。另外，Git 里“工作区、暂存区、提交”这三个概念虽然看过很多次，但一开始还是会混。

## 解决思路

这次先不追求内容多，而是把结构固定下来：笔记放 `docs`，练习代码放 `snippets`，每天的记录放 `logs`。这样至少以后回头看时不会太乱。对 Git 的理解上，我先用最朴素的方法记：工作区是正在修改的内容，暂存区是准备提交的内容，提交是正式保存的节点。先能把流程说清楚，再慢慢熟悉细节。
