# 学习日志 - 2026-05-10

## 今日学习

今天开始补 C++ 和前端的基础内容。C++ 这边没有急着写复杂程序，先从最基本的输入输出、`for` 循环和 `vector` 遍历开始。虽然语法比 Python 更严格，但也因此能更清楚地看到类型和结构的边界。前端部分我主要回顾了 HTML、CSS 和 JavaScript 各自负责什么，顺便写了一个数组方法的小示例，重新看了 `map` 和 `filter` 的基本用法。整体下来，内容都不深，但至少把几个方向都碰到了一遍。

## 遇到的问题

今天最明显的问题是切换语言时容易混淆细节。刚写完 Python 再看 C++，会下意识省略分号或者忘记声明类型；看 JavaScript 时又会把某些语法和 Python 的列表操作对照着记，结果反而有点乱。另一个问题是，如果只看单个语法点，很容易知道“怎么写”，但不太清楚“什么时候该这样写”。

## 解决思路

我先接受自己目前还处在打基础阶段，不要求一次就把不同语言完全区分清楚。更实际的做法是：每种语言都保留几个很小的示例，反复运行、反复改。这样通过对比代码和输出，慢慢形成感觉。对于“什么时候使用”这种问题，我准备先从最简单的场景记起，比如列表处理、循环遍历和数据保存，先建立基本直觉。
