# 学习日志 - 2026-05-09

## 今日学习

今天主要把注意力放在 Python 小练习上，尤其是列表处理和文件读取这两个最容易直接上手的部分。我写了一个简单的列表练习，把原始数据做排序、筛选和求和，代码不长，但能把几个常用操作串起来。之后又补了一个文件读取示例，练习如何打开文件、逐行读取以及统计内容。过程中我发现，只要示例足够小，理解起来就不会太吃力，比一上来做完整项目更适合现在这个阶段。

## 遇到的问题

问题主要出在细节上。比如 Python 的缩进虽然规则简单，但一不小心就会写错层级；另外在处理字符串时，我有时会忘记某些方法返回的是新值，而不是直接修改原变量。还有一个小问题是，自己写的示例如果依赖外部文件太多，后面复习时就不方便直接运行。

## 解决思路

我先尽量让每个示例独立运行，不依赖额外安装包，也尽量少依赖外部环境。这样以后不管在哪台机器上，打开就能跑，排查问题也更直接。对缩进和变量变化的问题，我准备养成一个习惯：每写完一个小步骤就运行一次，看输出是否符合预期，不等全部写完再一起检查。
